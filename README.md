# TechJob AI

אפליקציית חיפוש משרות הייטק וטכנולוגיה בישראל.
המשרות נאספות כל בוקר מלוחות הדרושים הציבוריים של חברות. כל משרה מסווגת לפי תפקיד, אזור ומודל העסקה, ומוצגת עם קישור אמיתי להגשת מועמדות.
המשתמשים נרשמים עם Google או עם אימייל וסיסמה, ומקבלים חשבון אישי עם:

- חיפושים שמורים
- משרות שמורות
- התראות חכמות
- פרופיל מקצועי וקורות חיים
- מעקב מועמדויות

ה־AI לומד מהלייקים והדיסלייקים של כל משתמש ומשפר את הדירוג בחיפוש הבא.

הכל רץ על חבילות חינמיות: **GitHub** לאחסון האתר ולאיסוף היומי, ו־**Firebase** (של Google) לחשבונות ולנתוני המשתמשים.

## מה יש בתיקייה

| תיקייה / קובץ | מה זה |
|---|---|
| `web/` | האפליקציה עצמה: `index.html`, `app.js`, `roles.js` (149 תפקידים), `config.js` (הגדרות) |

| `firebase/firestore.rules`, `firebase/storage.rules` | חוקי האבטחה: כל משתמש רואה ומשנה רק את הנתונים והקבצים שלו |

## שלב 1: העלאה ל־GitHub (כ־10 דקות)

1. פתח חשבון חינמי ב־[github.com](https://github.com), אם עוד אין לך.
2. לחץ על **New repository**. תן שם, למשל `techjob-ai`, בחר **Public** ולחץ **Create repository**.
3. העלה את כל הקבצים מהתיקייה:
   - **הדרך הפשוטה:** התקן את [GitHub Desktop](https://desktop.github.com), גרור אליו את התיקייה ולחץ **Publish**.
   - **דרך הדפדפן:** אפשר להשתמש ב־"uploading an existing file", אבל במק התיקייה `.github` מוסתרת. לחץ ‎Cmd+Shift+.‎ כדי לראות אותה ולהעלות גם אותה.

## שלב 2: הפעלת האתר והאיסוף היומי (כ־5 דקות)

1. ב־repository, היכנס ל־**Settings → Pages**. תחת **Source** בחר **GitHub Actions**.
2. היכנס ל־**Actions**, בחר **Collect jobs and deploy** ולחץ **Run workflow**.
3. אחרי 2–3 דקות האתר יהיה זמין בכתובת:
   `https://<שם-המשתמש-שלך>.github.io/techjob-ai/`

מעכשיו המשרות מתעדכנות לבד כל בוקר.
האפליקציה כבר עובדת במצב הזה עם משרות אמיתיות. בשלב הזה חשבונות המשתמשים נשמרים רק בדפדפן של כל משתמש.

## שלב 3: חשבונות בענן עם Firebase (כ־15 דקות)

1. **פתיחת פרויקט:** היכנס ל־[console.firebase.google.com](https://console.firebase.google.com) עם חשבון Google ולחץ **Create a project**. את Google Analytics אפשר לכבות.
2. **הוספת אפליקציית Web:** במסך הפרויקט לחץ על הסמל `</>` (Web), תן שם (למשל TechJob AI) ולחץ **Register app**. יופיע קטע קוד עם `firebaseConfig`. העתק אותו.
3. **הפעלת ההתחברות:** היכנס ל־**Build → Authentication → Get started**, ובלשונית **Sign-in method** הפעל:
   - **Email/Password**
   - **Google**: בחר אימייל לתמיכה ולחץ **Save**. אין צורך ב־Google Cloud Console, הכל מוגדר לבד.
4. **אישור כתובת האתר:** ב־**Authentication → Settings → Authorized domains** לחץ **Add domain** והוסף: `perezkobi-pixel.github.io`
5. **מסד הנתונים:** היכנס ל־**Build → Firestore Database → Create database**. בחר מיקום קרוב, למשל `me-west1` (תל אביב) או `eur3`, ובחר **production mode**. אחרי שהוא נוצר, היכנס ללשונית **Rules**, הדבק את התוכן של `firebase/firestore.rules` ולחץ **Publish**.
6. **חיבור האפליקציה:** הדבק את הערכים מ־`firebaseConfig` בקובץ `web/config.js`:
   ```js
   window.TJ_CONFIG = {
     firebase: {
       apiKey: 'AIza...',
       authDomain: 'techjob-ai.firebaseapp.com',
       projectId: 'techjob-ai',
       storageBucket: 'techjob-ai.firebasestorage.app',
       messagingSenderId: '...',
       appId: '1:...:web:...'
     }
   };
   ```
   שמור את הקובץ והעלה אותו ל־GitHub. האתר יתעדכן לבד תוך כמה דקות.
   הערכים האלה ציבוריים מטבעם. חוקי האבטחה מגינים על הנתונים, וכל משתמש יכול לגשת רק לנתונים שלו.

עכשיו הרשמה עם Google ועם אימייל וסיסמה עובדת, והחשבון זמין מכל מכשיר. כל משתמש חדש מקבל מייל אימות, ויש גם אפשרות "שכחתי סיסמה".

### שמירת קובץ קורות חיים (אופציונלי)

כדי לשמור קבצים צריך להפעיל ב־Firebase את Storage. בפרויקטים חדשים זה דורש לעבור לתוכנית **Blaze**, שמחייבת להזין כרטיס אשראי. השימוש עצמו נשאר בחינם עד מכסה גבוהה, ואפשר להגדיר תקרת תקציב.

1. היכנס ל־**Build → Storage → Get started**.
2. בלשונית **Rules** הדבק את התוכן של `firebase/storage.rules` ולחץ **Publish**.

בלי השלב הזה כל שאר האפליקציה עובדת. רק העלאת קובץ קורות החיים תציג הודעה שהשמירה לא הופעלה.

## הוספת חברות למאגר

כל שורה בקובץ `collector/sources.json` מתארת חברה אחת:

```json
{ "company": "Wiz", "ats": "greenhouse", "token": "wizinc", "type": "סייבר" }
```

איך מוצאים את ה־token: פותחים את עמוד המשרות של החברה ומסתכלים על כתובת עמוד משרה.

| מערכת | איך הכתובת נראית | ה־token |
|---|---|---|
| Greenhouse | `job-boards.greenhouse.io/wizinc/...` או `?gh_jid=` | `wizinc` |
| Lever | `jobs.lever.co/company/...` | `company` |
| Ashby | `jobs.ashbyhq.com/company/...` | `company` |
| SmartRecruiters | `jobs.smartrecruiters.com/Company/...` | `Company` |
| Comeet | `comeet.com/jobs/company/XX.XXX` | `XX.XXX:<token>` |

ב־Comeet, ה־token הציבורי מופיע בקוד המקור של עמוד המשרות.

13 החברות הראשונות ברשימה נבדקו ועובדות. השאר הן הצעות שעוד לא נבדקו: אם החברה לא משתמשת במערכת שרשומה, היא פשוט תדולג ותסומן ✗ בדוח.

את הדוח המלא אפשר לראות ב־**Actions** ←‎ הריצה האחרונה ←‎ **Collect jobs**.

**הרצה מקומית:** צריך Node 18 ומעלה. הפקודה הראשונה אוספת את המשרות, והשנייה מגישה את האתר בכתובת `localhost:8080`:

```bash
node collector/collect.js
npx serve web -l 8080
```

**קובץ אחד לטלפון:** הפקודה `node tools/build-single.js` יוצרת את `dist/TechJob-AI.html`. זה קובץ אחד שנפתח ישירות בדפדפן של הטלפון.

## איך זה עובד

- **איסוף:** רק ממשקים ציבוריים שהחברות עצמן מפרסמות לעמודי הקריירה שלהן (Greenhouse, Lever, Ashby, SmartRecruiters, Comeet). אין סריקה של LinkedIn, Facebook או אתרי דרושים שלא מאפשרים זאת. אתרים כמו AllJobs ודרושים IL יחוברו רק בהסכם שותפות או דרך API מורשה.
- **סינון:** נשמרות רק משרות בישראל, ורק כאלה שתואמות לאחד מ־149 תפקידי הטכנולוגיה (`web/roles.js`). משרות כספים, גיוס, מכירות וכדומה מסוננות החוצה.
- **עדכניות:** כל משרה שמוצגת נמצאה בלוח הדרושים של החברה באיסוף האחרון. משרה שהוסרה שם נעלמת מהאפליקציה למחרת.
- **ציון התאמה:** מחושב מכמה מרכיבים:
  - התאמה לתפקיד: עד 35
  - אזור: עד 15
  - מודל העסקה: עד 10
  - כישורים מול הפרופיל: עד 25
  - עדכניות: עד 15
  - למידה מלייקים: בין ‎−20 ל־+20
- **למידה מלייקים:** כל לייק או דיסלייק שומר את מאפייני המשרה: תפקיד, כישורים, חברה, רמה ומודל. משרות עם מאפיינים דומים עולות או יורדות בדירוג.

## השלבים הבאים (לא בגרסה הזו)

- **הבנת חיפוש חופשי ב־AI:** Firebase Cloud Function שקוראת ל־Claude API ומפרשת בקשות בשפה חופשית.
- **התראות במייל ובטלפון:** Firebase Cloud Messaging (התראות פוש) ותזמון של Cloud Functions.
- **מקורות נוספים:** יותר חברות, ואתרי דרושים בהסכם.
- **אפליקציה לחנויות:** אפשר לעטוף את האתר עם Capacitor.
